Sample exam (for reviewers)

  1. Download the sample exam file to the Desktop or Downloads folder.
  2. Open Testi. The sample exam is selected automatically (or use the button "קובץ אחר…" to pick it).
  3. Type any name in the first box, any digits (e.g. 123456782) in the second, and the access code TEST-2345 in the third.
  4. Press the large blue button. The exam opens full-screen; it ends normally when you press the blue "submit" button at the bottom left and confirm.
